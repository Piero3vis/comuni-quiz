## ADDED Requirements

### Requirement: The published artifact is the self-contained single file
The file to publish SHALL be `dist/quiz.html`, generated by `scripts/build_single_file.py`, served as `index.html` at the site root. It MUST NOT load any external script, stylesheet, font or data file; the only external URLs it contains are ordinary links (`<a href>`) in the footer.

#### Scenario: No external resources
- **WHEN** `dist/quiz.html` is inspected
- **THEN** it contains no `<script src=…>`, no `<link rel="stylesheet">` and no `fetch` of a file that is not inlined (the data is read from `<script id="data">`)
