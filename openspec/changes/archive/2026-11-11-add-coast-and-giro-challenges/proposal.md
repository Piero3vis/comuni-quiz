## Why

Today's achievements are all about *which* comuni you find. Nothing rewards *where they are relative to each other*: crossing the peninsula from one sea to another, or touring Italy region by region. These need two facts the data does not have: which comuni border each other, and which sea each coastal comune faces.

## What Changes

- **New data `data/geo.json`**, generated by `scripts/build_geo.py` (stdlib only) from `data/map.json`:
  - comune adjacency (shared boundary segments);
  - the sea of each of the 644 coastal comuni (Ligure, Tirreno, Ionio, Adriatico, Canale di Sicilia, Mar di Sardegna);
  - the island comuni (everything not connected to the peninsula, except the exclave Campione d'Italia).
  It is loaded with the other data files and embedded in `dist/quiz.html`.
- **"Da costa a costa"** category, 9 achievements: Tirreno–Adriatico, Adriatico–Ionio, Ionio–Tirreno, Ligure–Adriatico, Ligure–Tirreno, Ligure–Ionio, Tirreno–Canale di Sicilia, Ionio–Canale di Sicilia, Tirreno–Mar di Sardegna. A pair counts when two found coastal comuni on those seas are joined by a chain of found **inland** comuni (at least one) that border each other. Derived from the found comuni, so the order of guesses does not matter.
- **Challenge "Giro d'Italia a tappe"** (order of guesses): a run of consecutive guesses where each new comune is in the same region as the previous one or in a bordering region. Capoluoghi and island comuni are forbidden and end the run, as does a jump to a non-bordering region (a new run starts from that comune when it is allowed). Earned when one run touches all 18 regions of the peninsula. The run in progress is saved with the game.
- **Super-challenge "Italia a piedi"** (map, any order): the found comuni of the peninsula, capoluoghi excluded, contain one chain of bordering comuni that touches all 18 regions.
- Toasts when a pair, a Giro stage in a new region, a broken Giro (from 3 regions up) or a challenge is completed; progress shown in the side panel.

## Capabilities

### New Capabilities
- `geo-data`: comune adjacency, sea of each coastal comune and island comuni, generated from the map data.
- `coast-to-coast`: the nine sea-to-sea achievements.
- `giro-challenge`: the order-based region-by-region run.
- `walk-challenge`: the "Italia a piedi" super-challenge.

### Modified Capabilities
None (`openspec/specs/` is empty).

## Non-goals

- Drawing the Giro route or the chains on the map (possible later).
- Changing existing achievements: the existing "Giro d'Italia" (one comune per region) stays as it is.
- Sea assignment by official hydrographic polygons: rules by region/province with explicit cut points are used instead (see design).

## Impact

- New: `scripts/build_geo.py`, `data/geo.json` (~150 KB before compression).
- `app.js` (loading, union-find for chains, Giro run, panel categories, toasts), `scripts/build_single_file.py`, `tests/smoke.js`.
- `localStorage['comuniQuizV1']` gains `gr` (Giro run: last region and regions visited); `a` can contain `giro`. Older saves keep working.
- Docs: `README.md`, `DEVELOPMENT.md`, `CLAUDE.md`.
