# CLAUDE.md

Static, framework-free quiz page. UI language: Italian. No build step for the app itself; only the map data has a build script.

## Architecture
- `index.html` + `style.css` + `app.js`. `app.js` loads `data/map.json` and `data/groups.json` (or the inline `<script id="data">` that
  `scripts/build_single_file.py` embeds), then runs everything inside `main()`.
- The map is drawn on one `<canvas>` with a `Path2D` per comune; the view is `scale`, `ox`, `oy`. Everything is redrawn on change via `draw()` (rAF-batched).
  Region outline (`rb`) and province outline (`pb`) are single paths stroked on top with constant on-screen width.
- Hit testing uses `isPointInPath` on a scratch canvas context (`hc`) over all comuni; it is only used for hover and click.

## Data format (`data/map.json`)
Parallel arrays, indexed by comune number `i` (0..7895):
- `n[i]` name (Alto Adige/Aosta names may be `Italiano/Tedesco`), `p[i]` province acronym, `r[i]` index into `regs`.
- `d[i]` SVG path string in projected integer units (`x = lon*cos(41.9deg)*800`, `y = -lat*800`; first `M` absolute, then relative `l`, `z`).
- `bb` bounding box `[minx, miny, maxx, maxy]` in the same units. `rb` and `pb`: region and province outlines as path strings.
- `co`: indices of coastal comuni. `regs`: region names, sorted.
Never edit `map.json` by hand: change `scripts/build_data.py` and regenerate.

## ISTAT data (`data/extra.json`)
Generated by `scripts/build_extra.py` (stdlib only), aligned to `map.json` indices, merged into `D` by `loadData()` (throws if `pop` length differs):
`pop[i]` residents on 1 January 2025 (POSAS 2025), `cap` capoluogo indices (ISTAT flag, co-capoluoghi included), `rec` record comuni
(`nord`, `sud`, `est`, `ovest`, `grande`, `piccolo` from unsimplified openpolis borders; `popoloso`, `spopolato` from `pop`).
Matching: (name, sigla) → openpolis catasto code → ISTAT elenco → 2017-2025 code → POSAS; comuni merged in 2026 use openpolis' code.
Rerun it after regenerating `map.json`.

## Geo data (`data/geo.json`)
Generated by `scripts/build_geo.py` (stdlib) from `map.json`, merged into `D` by `loadData()` (throws if `sea` length differs). Rerun after regenerating `map.json`.
`nb[i]`: neighbours with a higher index as positive deltas (two comuni border when they share a boundary segment); `app.js` rebuilds `NB[i]` (symmetric).
`seas`: Ligure, Tirreno, Ionio, Adriatico, Canale di Sicilia, Mar di Sardegna; `sea[i]`: index for comuni in `co`, -1 otherwise (majority of the coastline, cut points in `sea_of()`, Messina forced to Ionio).
`ins`: island comuni (not connected to the peninsula; Campione d'Italia is an exclave, not an island). In `app.js`: `INS`, `MAIN[i]`, `RADJ[k]` (bordering regions on the peninsula), `MREGN` (18).

## Groups (`data/groups.json`)
`isole`, `cammini`, `confini`, `marinare`, `storia`: lists of `{ name, comuni: [names], nota? }`. A group with `"union": true` is every other group in its list plus its own extra `comuni`.
`nota` is a short anecdote shown in the toast and under the unlocked achievement (hidden while locked, since it can give the answer away).
`withGroups()` in `app.js` converts names to `[name, indices, nota]` and throws if a name is missing or not unique (Samone, Livo, Peglio, Castro, San Teodoro are duplicated names in the data):
write a duplicated name as `"Livo (CO)"`.
`confini` (comuni bordering France, Switzerland, Austria, Slovenia, San Marino, Vatican) is generated by `scripts/border_comuni.py --write` (needs shapely):
geometry from openpolis + Natural Earth, plus `EXTRA` for very short borders, checked against the "Comuni confinanti" box on Wikipedia. Do not edit it by hand.

## Curiosità (`data/facts.json`)
`{ "Nome": { "testo": "…", "fonte": "https://…" } }`, alphabetical (same naming as groups, `"Livo (CO)"` for duplicates), resolved by `withGroups()` into `D.fact` (Map index → `testo`), embedded by `build_single_file.py`.
Shown as a toast "💡 Curiosità su <nome>: …" when the comune is found (end of `achCheck(i)`, live guesses only) and in the click box (`clickAt()`) as a closed `<details class="fact">`: "💡 Indizio: una curiosità" before the comune is found, "💡 Curiosità" under residents/rarity after.
Rules (checked by `tests/smoke.js`): every entry has an `https` `fonte` supporting the whole text; no capoluoghi; texts never contain the comune's name or a `/` part, ≤ 200 characters, typographic apostrophe; avoid yearly numbers.
Goal: one per province (the test prints uncovered provinces); done by region: Veneto. `placeInfo()` keeps the box inside the map.

## Quiz logic
- Matching: `norm()` strips accents/non-alphanumerics; `keyMap` maps normalised names (and each `/` part) to indices.
  `looseMap`/`lk()` is the fallback that also drops connecting words (di, del, della, nell, ...). Typing a name fills every comune with that name
  (homonyms: both Castro, etc.; covered by `tests/smoke.js`).
- State: `found[]` (Uint8Array), `foundCount`, `popFound` ("persone beccate", `#pop`) and `rarFound` ("punti rarità", `#rar`: `RAR[i] = max(1, round(10·log10(maxPop/pop)))`), both top-left on the map, `regCount`, `provFound`, `coastFound`, timer in `elapsed`.
- Persistence: `localStorage['comuniQuizV1'] = { f: [found indices], t: elapsedMs, a: [earned challenge ids], rb: { timed id: record }, tr: { giro, giroP: [last unit, [units]] } while a run is on (old gr still read), g: 1 if given up }`.
  Game over (`over()`: given up or all found) → `showOver()`; `#go` becomes "Ricomincia", which removes `comuniQuizV1` and reloads. Always wrapped in try/catch.
- Provinces: `PN` maps sigla to display name, `CM` lists ISTAT metropolitan cities, `provLabel(p)` gives "Città metropolitana di …" / "Provincia di …" for toasts.
  `scripts/check_istat.py` checks `map.json`, `PN` and `CM` against ISTAT's current list.

## Theme
Three modes: automatic (no `data-theme` on `<html>`, follows `prefers-color-scheme`), `light`, `dark`. The `#theme` button cycles them and stores the
choice in `localStorage['comuniQuizTheme']` (removed for automatic), separate from `comuniQuizV1`. An inline script in `<head>` applies it before first paint.
`render()` reads colours from CSS variables, so call `draw()` after any theme change (button and `matchMedia` listener do).

## Achievements
Derived from the state, never stored, except challenges (`CH`: the timed challenges in `TIMED` and `giro`, `giroP`, see below), whose ids are saved in `a` and restored into `earned`: `achInit()` computes the unlocked set silently on load, `achCheck(i)` adds new ones and queues toasts.
Ids: `m<n>` milestone, `s<n>` secret (`SEC`: shown as "🔒 ???" until unlocked), `sw:<key>` strategy wink (`WINKS`: `n` correct new guesses in a row whose name fits the theme, one per guess even for homonyms; santi 5, gallo 3, cervi 3, parole 3 from `PAROLE`; any other correct guess resets the streak, wrong and duplicate guesses do not; saved in `earned` via `CH`; "🔒 ???" in Segreti until unlocked; never list them in README or DEVELOPMENT.md), `pp<q>` population milestone (`PPS`: q% of residents, on `popFound`), `p:<ACR>` province complete, `r:<k>` region complete, `p25/p50:<ACR>` and `r25/r50:<k>` quarter/half,
`e:r`/`e:p` at least one comune in every region/province ("Giro d’Italia", "Giro delle province"), `cap` all capoluoghi, `b<limit>:<n>` borghi (`BG`: comuni under 1000/500/100 inhabitants), `t<n>` provincial treasures (`TES`: least populated comune per province), `x:<key>` record comune (`REC`, keys of `rec`), `c<n>` coast milestone, `k:<k>` regional coast, `i:<gi>` island group, `w:<gi>` cammino, `h:<gi>` / `mr:<gi>` / `f:<gi>` history, maritime republic and border groups (`TG`), `f:giro` one comune on every foreign border. Because nothing is persisted, reordering groups is safe.
Provinces with fewer than 4 comuni get no quarter/half achievements.
Timed (`TIMED`, category "A tempo"): `{id, ic, l, n, ms, ok?, key?, what?}`, unlocked when `n` comuni passing `ok` (same `key`, e.g. initial letter) are found within `ms` of game time (`Date.now()-t0`, so pauses do not count); `timedCheck(added)` in the input handler keeps a sliding window per challenge and key (not saved) and the record `best`, saved as `comuniQuizV1.rb = { id: n }`. `raffica` keeps its old id.
Geography (from `geo.json`), updated in `addFound()` so a reload rebuilds them: `cc:<xy>` "Da costa a costa" (`CC`, sea letters `LTIACS`): union-find `ccP` over found inland comuni, `ccM` sea bitmask of found coastal neighbours, `ccE` one example comune per sea, `ccDone` id → [from, to];
`walk` "Italia a piedi": union-find `wkP` over found peninsula comuni (`MAIN`, capoluoghi included), `wkM` region bitmask, `wkBest`/`wkBestM` best region count and mask; it weighs `WALKW` (10) in the total.
`giro` / `giroP` "Giro d’Italia a tappe" / "Giro delle province a tappe" depend on the order of guesses. Paused: `TOURS_ON = false` empties `TOURS` (no rows, no steps); `load()` keeps a saved `tr` in `trKept` and `save()` writes it back, `giro`/`giroP` stay in `a`; the tour tests in `tests/smoke.js` run only when it is `true`. Rules: `TOURS` (unit = region index or province sigla, `adj` = `RADJ` / `PADJ`, `total` 18 / 93),
`tourStep(t, added)` in the input handler (not on load); state `t.last` (or null) and `t.seen` (Set), saved as `comuniQuizV1.tr = { giro: [last, [units]], giroP: [...] }` (an old `gr: [region, mask]` is still read).
Stages must be `allowed()` (peninsula, not capoluogo). `tourStatus(t)` writes the panel status; `missing()` lists up to 8 names, otherwise counts.

## Side panel
Two tabs (`.tabs`, `#paneR` / `#paneA`, not saved). Regions: `buildSide()` makes one `<details class="reg" id="rg<k>">` per region, `updateReg(k)` fills percentage (`pct()`: floor, "<1%", "100%" only when complete), count, bar and province rows;
`sortRegs()` orders them with CSS `order` (`regSort`: `az`, `pct`, `miss`) so open `<details>` survive. Achievements: `achCats()` returns the categories `{k, ic, t, info?, items: [{u, ic, l, c, d?, h?, s?}], more?}` (`d` detail shown once unlocked, `h` rule and `s` status always shown, used by challenges; `w` weight in the header total and bar, default 1, rendered as `data-w`),
`renderAch()` draws the total, the filter (`achFilter`: `all`, `done`, `todo`) and one `<details class="cat" data-a>` per category; `openAch` keeps them open across re-renders. New achievements go in `achCats()`.

## Conventions
- Keep it dependency-free (no framework, no bundler). Theme colours live in CSS variables with a dark-mode override.
- Do not move the camera on guesses except through `ensureVisible()` (pan only if the new comune is entirely off screen).
- Italian user-facing strings. Typographic apostrophe in prose, straight quotes in code.
- The footer must keep the CC BY 4.0 attribution (ISTAT, openpolis link, licence link, "semplificati e modificati") and the "Nessun cookie" note.
  No cookies and no external resources except the GoatCounter visit counter (one `async` script tag at the end of `index.html`, `https://gc.zgo.at/count.js`, cookieless; the footer says so). Never send progress or guesses, never add events or other trackers. Only `dist/quiz.html` is published (as `index.html`).
- Support link: the only external links are ordinary `<a>` elements: the attribution links and the Ko-fi support link (`#support` in the footer, `#supportSide` in the side panel, whose `href` `app.js` copies from the footer: change the URL in `index.html` only, plus `.github/FUNDING.yml`).
  Both open in a new tab with `rel="noopener noreferrer"`. No Ko-fi widget, button script, iframe or image; never in toasts, popups or triggered by game events; nothing locked behind it (`tests/smoke.js` checks all of this).
- Search tags (title, description, canonical, Open Graph, JSON-LD, inline SVG favicon) and the `.about` text live in `index.html`.
  They hard-code the site URL and the 7.896 count: update them if either changes (e.g. after the 2026 mergers); `tests/smoke.js` checks that the URLs agree.

## Commands
`python3 -m http.server 8000` (dev), `npm test` (builds the single file and runs the jsdom smoke test),
`python3 scripts/build_data.py` (regenerate map data; needs shapely and Node), `python3 scripts/build_extra.py` (regenerate `data/extra.json`), `python3 scripts/build_geo.py` (regenerate `data/geo.json`), `python3 scripts/build_single_file.py`,
`python3 scripts/check_istat.py` (compare with ISTAT). Node must be 22.23.4+, 24.22.1+ or 26.12.1+ (Brotli security fix; `engines` + `.npmrc` engine-strict enforce it, CI pins 22.23.4).

## Workflow
Spec-driven with OpenSpec: changes live in `openspec/changes/<name>/` (proposal, design, specs, tasks); `/opsx:propose`, `/opsx:apply`, `/opsx:archive`.
Run `openspec validate <change> --strict` before applying.
One branch and one pull request per change; `.github/workflows/pages.yml` tests every PR (Node 22.23.4, `npm test`) and deploys `main` to
https://piero3vis.github.io/comuni-quiz/ (only `dist/quiz.html` as `index.html`). Never push straight to `main`.
